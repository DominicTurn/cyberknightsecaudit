# cyberknightsecaudit
A basic email security audit

Cyber Knight Sec Scout

A Java console application that performs a basic email security audit by inspecting
public DNS records for SPF and DMARC authentication.

Features

• Live DNS lookups
• SPF detection
• DMARC detection
• Input validation
• Plain-English assessment
• Object-oriented Java design

Technologies

• Java 21
• JNDI DNS
• Java Collection

Future Roadmap

• DKIM verification
• DNSSEC
• MTA-STS
• PDF reports
